# Quick vim tutorial

1.  Calling vim on a nonexisting file creates a new file at that location.&nbsp;
2.  To move your cursor to the last character press "shift" + "g".
3.  To modify the file, press "i", and adjust cursor using the arrow keys.
4.  To finish modifying press "Esc".
5.  To finish editing, press "shift" + ":", and the console will appear at the bottom of the screen.
6.  Type "wq" into the terminal to write (save) and quit
    1.  If you want to quit without saving type "q!"
